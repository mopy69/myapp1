## 🛠️ Comandos del Proyecto (Next.js 16 + React 19 + Tailwind v4)
*   **Servidor de desarrollo:** `npm run dev`
*   **Compilar la aplicación:** `npm run build`
*   **Arrancar en producción:** `npm run start`
*   **Linteo de código:** `npm run lint`

---

## 🚀 Pautas de Trabajo
1.  **Tecnologías:** Next.js App Router, Tailwind CSS v4, Lucide Icons.
2.  **Estilo de Código:** Utilizar TypeScript estricto, Client Components marcados con `"use client"` únicamente cuando sea estrictamente necesario para interactividad o hooks.
3.  **Estética Premium:** Toda interfaz o cambio en el frontend debe ser visualmente impactante, con micro-animaciones fluidas (`transition-all`, `hover:scale`), sombras y diseño adaptativo.
